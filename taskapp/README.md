# タスク管理アプリ（Trelloライク） 要件定義書

## 1. 概要
Trelloのようにリスト（列）とカードを使ってタスクを管理できる、
ドラッグ&ドロップ対応のタスク管理アプリを作る。

本アプリでは、Board・List・Cardとカード移動というTrelloの基本操作モデルを参照する。Trelloとの機能互換や完全な再現を目的とせず、単一利用者向けの学習用MVPとして実装する。

## 2. 目的
- Trelloの基本的な操作感（リスト間でカードを移動する）を体験できるアプリを作る
- React / コンポーネント設計 / 状態管理 / ドラッグ&ドロップの実装を学習する

## 3. スコープ（MVP範囲）

### 3.1 含む機能
- ボードは1つのみ（複数ボード管理は対象外）
- リスト（列）の作成
- リストの削除
- リストのタイトル編集
- カードの作成（リストに対して1件追加）
- カードの削除
- カードのタイトル編集
- カードをドラッグ&ドロップでリスト間・リスト内で移動できる
- データはブラウザのlocalStorageに保存し、リロードしても消えない
- 保存済みデータがない初回起動時は、操作方法を理解するためのサンプルリスト・カードを表示する
- キーボード利用者にも、カード移動の代替操作を提供する
- ボード、リスト、カードの視覚的な階層と横並びのレイアウトはTrello風とする

### 3.2 含まない機能（将来の拡張候補）
- 複数ボードの作成・切り替え
- カードのラベル・色分け
- カードの期限（締切日）
- カードの説明文・チェックリスト・コメント
- 担当者・アイコン表示
- 検索・フィルタ機能
- 複数人での共同編集（バックエンド・DB連携）
- ログイン・ユーザー管理
- リストの並び替え（リスト自体の順番入れ替え）

## 4. 技術構成
- フロントエンド: React + Vite
- 言語: JavaScript（またはTypeScript、後続ステップで決定）
- ドラッグ&ドロップ: ライブラリ導入予定（例: @dnd-kit）※技術選定ステップで決定
- データ保存: ブラウザのlocalStorage
- バックエンド: なし（MVP範囲では不要）

## 5. データ構造（概要）

```
Board
 └─ lists: List[]

List
 ├─ id: string
 ├─ title: string
 └─ cards: Card[]

Card
 ├─ id: string
 └─ title: string
```

※詳細な型定義は「データ設計」ステップで確定する。

## 6. 画面構成（概要）
- ボード画面（1画面のみ）
  - 複数のリストが横並びに表示される
  - 各リストの中にカードが縦に並ぶ
  - リスト追加ボタン、カード追加ボタンを配置
  - カードをドラッグして別のリストや同じリスト内の別の位置に移動できる

※詳細なワイヤーフレームは「画面設計」ステップで作成する。

## 7. 受け入れ条件（この機能ができたらMVP完成とみなす基準）
- [ ] リストを追加できる
- [ ] リストを削除できる
- [ ] リストのタイトルを編集できる
- [ ] カードを追加できる
- [ ] カードを削除できる
- [ ] カードのタイトルを編集できる
- [ ] カードをドラッグ&ドロップで別のリストに移動できる
- [ ] カードをドラッグ&ドロップで同じリスト内の順番を変更できる
- [ ] ブラウザをリロードしてもデータが保持されている
- [ ] 空のリストへカードを移動でき、移動を取り消した場合はデータが変わらない
- [ ] 空白だけのリスト名・カード名を登録できない
- [ ] 削除確認を取り消した場合はデータが変わらない
- [ ] 保存済みデータの破損または保存失敗時にも、画面が停止しない
