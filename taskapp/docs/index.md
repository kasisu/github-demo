# タスク管理アプリ 資料一覧

このディレクトリには、学習用MVPの要件・設計資料を置く。実装時は、ここに記録した決定事項を基準にする。

| 資料 | 内容 | 状態 |
|---|---|---|
| [要件定義書](requirements.md) | 目的、MVP範囲、対象外、概要の受入条件 | 既存 |
| [概念設計図](design-overview.md) | 画面構成、操作フロー、データフロー、概念データモデル | 既存 |
| [機能要件](functional-requirements.md) | 画面上で利用者ができる操作と、その振る舞い | 作成済み |
| [画面設計](screen-design.md) | ボード画面の構成、表示状態、操作ごとのUI要件 | 作成済み |
| [非機能要件](non-functional-requirements.md) | 利用環境、品質、永続性、保守性、セキュリティの条件 | 作成済み |
| [データ設計](data-design.md) | Board・List・Cardの項目、関係、localStorage保存形式 | 作成済み |
| [技術スタック](tech-stack.md) | 採用技術、採用理由、未確定の技術選定 | 作成済み |

## 読む順番

1. 要件定義書で、目的とMVP範囲を確認する。
2. 概念設計図と画面設計で、利用者が操作する画面と流れを確認する。
3. 機能要件とデータ設計で、実装する振る舞いと状態を確認する。
4. 非機能要件と技術スタックで、品質条件と実装上の制約を確認する。
